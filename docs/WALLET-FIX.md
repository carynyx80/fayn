# Wallet and branding update

The owner-provided Fayn PNG is used without image modification as the sidebar logo, favicon and connection-dialog brand image. The public page now says "Partnering with the first project that will use Fayn." The "not launched" and "read-only preview" labels were removed; unavailable transaction actions and accurate contract status remain disclosed.

Wallet improvements: official pinned SignClient UMD browser distribution is shipped unchanged, removing custom SDK bundling; account-only optional namespaces support Ethereum bootstrap and Robinhood Chain; no transaction or signing permissions. Pairing has initialization, relay and approval timeouts, retry handling and cancellation guards. A direct EIP-1193 account connection is available inside a wallet Web3 browser. Account and chain changes invalidate displayed connection state. Sessions are reusable and disconnect clears the displayed account.

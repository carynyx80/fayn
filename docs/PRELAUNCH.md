# Current public release

The hosted site is a partnership preview with direct browser-wallet connection to Robinhood Chain mainnet (4663). No simulated balances or trading actions ship. Account access and network changes require wallet approval. See WALLET-FIX.md for connection behavior and limitations. The local EVM research application is retained in source and excluded from the public build. Contracts are not deployed and no independent audit is claimed.

Vercel builds with npm run build, output dist, Node 24. The owner's GitHub integration deploys main automatically. Public site: https://fayn-navy.vercel.app/

# Fayn typography

Self-hosted variable fonts downloaded from the official Google Fonts repository on 2026-10-17. Font files are unmodified and licensed under the SIL Open Font License 1.1. The accompanying OFL files include attribution and license terms.

* Instrument Sans: interface text, 400–700. https://github.com/google/fonts/tree/main/ofl/instrumentsans
* Syne: wordmark, headings and navigation, 400–800. https://github.com/google/fonts/tree/main/ofl/syne
* Bodoni Moda: editorial display and numeric statements, 400–900, regular and italic. https://github.com/google/fonts/tree/main/ofl/bodonimoda

Fonts are served from the same origin; no Google Fonts CDN or tracking request is made at runtime.
